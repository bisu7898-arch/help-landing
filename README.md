# H.E.L.P · 가족 교육 커뮤니티

> 학원 대신, 봉사하고 여행하며 배우는 우리 가족.
> AI 시대, 부모도 아이도 함께 성장하는 가족 교육 커뮤니티 **H.E.L.P** 의 상세페이지입니다.

*Heartwarming Experience & Learning Project · Learn by Doing, Grow Together.*

## 구조

```
.
├── index.html      # 랜딩 페이지 (단일 파일)
└── images/         # 이미지 자산
```

순수 정적 HTML/CSS/JS로 작성되었으며 빌드 단계가 필요 없습니다.

## 활동

- **가족봉사** — 받기보다 나누는 가족이 됩니다.
- **가족러닝저니** — 세상이 곧 교실입니다.
- **초록지붕 하브루타 살롱** — 질문이 자라는 거실입니다.
